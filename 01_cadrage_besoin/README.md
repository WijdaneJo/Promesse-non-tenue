# 01 — Cadrage du besoin

Définition du problème métier avant toute manipulation de données :
contexte, problématique, périmètre, règles de gestion et métriques.

## Contenu

| Fichier | Description |
|---|---|
| `note_de_cadrage.md` | Note de cadrage — version 2.0, révisée après qualification |
| `regles_et_metriques.md` | 11 règles de gestion et 17 métriques |

## Principe

Le cadrage est un document vivant. La version 1.0 posait des hypothèses
sur ce que la donnée permettait ; la version 2.0 intègre les résultats
de la qualification (dossier 02) et ajuste le périmètre en conséquence.

L'historique des versions est tracé dans la note elle-même.
